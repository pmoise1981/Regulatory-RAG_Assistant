# FFIEC Demo Note: Operational Resilience Controls

This demo note supports local testing of cited retrieval behavior. It is not official FFIEC guidance.

Operational resilience programs typically combine governance, business impact analysis, incident response, backup and recovery, vendor dependency tracking, access controls, and management reporting.

Common control evidence includes:

- incident response procedures
- system recovery objectives
- test results
- exception and remediation logs
- access review records
- dependency inventories
- board or management reporting

When using AI to summarize operational resilience evidence, the workflow should preserve citations, retrieved excerpts, confidence indicators, and reviewer approval status.
