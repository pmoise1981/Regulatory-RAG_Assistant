# Basel Framework Demo Note: G-SIB Systemic Importance

This demo note summarizes concepts used for local testing of the Regulatory RAG Assistant. It is not a substitute for official Basel Committee text.

Global systemically important banks, or G-SIBs, are assessed using an indicator-based approach intended to measure the impact that a bank's failure could have on the global financial system and wider economy.

The Basel framework groups systemic importance indicators into five broad categories:

- size
- cross-jurisdictional activity
- interconnectedness
- substitutability or financial institution infrastructure
- complexity

The methodology emphasizes that systemic importance is related to global impact, interconnected financial activity, substitutability of critical services, and the complexity of resolving a large banking organization.

For audit-ready analysis, a regulatory answer should cite the specific source document and distinguish between directly retrieved regulatory language and analyst interpretation.
